# Hi, I'm Sami

I figure out where AI actually fits in how things run, then make it real with the integrations, the workflows, the guardrails and getting people to use it.

Two of the pinned repos are MCP servers I built for my own use. They run my notes, plans and side projects, and I use them most days. Both are designed around one idea. When an AI agent acts on your behalf, its mistakes should be small, visible and reversible.

- **[obsidian-guarded-mcp](https://github.com/cyber-sami/obsidian-guarded-mcp)** lets Claude read, search and edit notes across several Obsidian vaults, with path guards, soft delete and exact-match edits.
- **[trello-guardrails-mcp](https://github.com/cyber-sami/trello-guardrails-mcp)** lets Claude organise Trello boards by name, with archive-only writes and no guessing on ambiguous names.

I design the tools, the guardrails and the tests, and Claude Code writes the code. I review it, run it on my own data and maintain it.
